# BP-Wiki Pricing

BP-Wiki Starter is free to use.

Version `1.1.1` uses `Public OS Shell` as the public-safe BP-Wiki system layer.

This repository does not include a paid Runtime pack, in-plugin checkout, account login, license validation, or automatic subscribed downloads.

## Editions

| Edition | Price | Best For | Includes |
| --- | ---: | --- | --- |
| Free Starter | Free | New Obsidian users and knowledge-base builders | 12 bilingual starter templates, setup guide, template selector, edition comparison |
| Public OS Shell | Free | Users who want to understand BP-Wiki as an AI-assisted knowledge operating system | Public architecture, README / AGENTS-style operating shell, minimal Runtime concepts, synthetic examples, distribution manifest |
| Developer Core | Not bundled | Advanced users who want reproducible mechanics | Public-safe packs, templates, toy projects, and shareable skills when released separately |
| Private Brain | Not distributed | The original user's production system | Private projects, skills, data sources, decision records, learning records, and connector state |

## Distribution Boundary

Public OS Shell is a derived distribution. It is the public operating-system shell, not the full private BP-Wiki system.

It may explain the architecture, folder conventions, Runtime concepts, agent entry contract, public/private boundary, and starter workflow. It must not include private projects, company data, AI Staging, connector configs, secrets, local paths, private skills, real data sources, decision ledgers, or learning logs.

Developer Core and Custom Implementation, if offered later, should use separate terms, distribution manifests, and redaction review. They are not included in this free plugin release.
