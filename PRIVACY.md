# Privacy Policy

BP-Wiki Starter version `1.0.0` runs locally in your Obsidian vault.

## Data Collection

The plugin does not collect, store, transmit, or sell personal data.

## Network Use

Version `1.0.0` does not make network requests.

## Telemetry

The plugin does not include client-side telemetry or analytics.

## Payments and Accounts

The free starter plugin does not require payment or an account. Optional paid BP-Wiki Pro and Custom services may be offered outside this plugin. If a future version adds license validation, account login, or subscribed content-pack downloads, this policy and the README will be updated before release.

## Local Files

The plugin only creates Markdown files and folders inside the current Obsidian vault, under `BP-Wiki Starter/` by default.
