# Privacy Policy

BP-Wiki Starter version `1.1.6` runs locally in your Obsidian vault.

## Data Collection

The plugin does not collect, store, transmit, or sell personal data.

## Network Use

Version `1.1.6` does not make background network requests.

## Telemetry

The plugin does not include client-side telemetry or analytics.

## Payments and Accounts

The free starter plugin does not require payment or an account.

In-plugin purchase, automatic renewal, and license activation are not active in version `1.1.6`. If a future version adds license validation, account login, or automatic content-pack downloads, this policy and the README will be updated before release.

## Local Files

The plugin only creates Markdown files and folders inside the current Obsidian vault, under `BP-Wiki Starter/` by default.

Public OS Shell files generated by the plugin are starter materials. They do not require users to upload private notes, connect accounts, expose credentials, or share company or client material.
