# Privacy Policy

BP-Wiki Starter version `1.1.3` runs locally in your Obsidian vault.

## Data Collection

The plugin does not collect, store, transmit, or sell personal data.

## Network Use

Version `1.1.3` does not make background network requests.

## Telemetry

The plugin does not include client-side telemetry or analytics.

## Payments and Accounts

The free starter plugin does not require payment or an account.

In-plugin purchase, automatic renewal, and license activation are not active in version `1.1.3`. If a future version adds license validation, account login, or automatic content-pack downloads, this policy and the README will be updated before release.

## Local Files

The plugin only creates Markdown files and folders inside the current Obsidian vault, under `BP-Wiki Starter/` by default.

Public OS Shell files generated by the plugin are synthetic starter materials. They do not contain private projects, data sources, decision records, AI staging raw outputs, learning logs, connector configs, secrets, or local paths.
